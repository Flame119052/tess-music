## 13 Nov morning — a user's install fails

- A user ran the install line over an old 0.1.0 install: "Spotify's files look incomplete", then a black window,
  then "Spotify isn't installed". Reinstalling Spotify was not an option.
- Found in stages: the installer closed Spotify and paused the helper before failing; its report used `python3`
  (only an install prompt on her Mac); fresh installs hit a `set -e` trap; and the root cause: the 0.1.0 helper's
  Spicetify apply deleted Spotify's interface folder and macOS blocked the copy back.
- Repaired her Mac remotely through the installer itself (it recognised the patcher's backup by SHA-256), then made
  delete-then-copy impossible everywhere with a safe swap and a CI release gate (#36, D-18, D-19).
- Built the doctor, anonymous health reports to a private Cloudflare inbox, and the rescue line (#37, D-14–D-17);
  inbox moved to `tess-music-player.janus.ing`, Access bypass added by the owner, free-tier caps.

## 13 Nov afternoon — performance hill climb (#35)

- Built measuring tools (`bench`, `cpu-ab`, `ab`, traces). Learned to measure with the window visible (hidden windows
  draw nothing) and not to trust macOS `ps %cpu` (a minute-long average).
- Findings, in the order found: Spicetify's endless searches for renamed Spotify parts; the closed player still
  running; broad `:has()` rules re-checking the page on every change; Spotify's `will-change` on every button; shelf
  arrows' always-running scroll animations; and the big one, endless motion redrawing the whole Retina window.
- Result: CPU at rest on Home 71% → 29% (Spotify alone ~24%); clicks 56–88 ms; worst freeze 318 → 72 ms.
  "Under 200 MB" shown to be unreachable (Spotify alone ~1.2 GB) (D-50–D-55).
- Fixed along the way: Home bar black slab (#38), progress line full at song start (#39).

## Lessons

- Test the failure paths, not just success: every incident today was a failure path nobody had run.
- Background-window measurements lie; measure what the user sees.
- Write the issue when the ask arrives; back-filling is expensive.
- A gate in CI is worth more than a careful promise.
